# LEC AI Agent — Project Rules

This is a Python project. All code is Python 3.14.

## Code Style
- Use type hints on every function signature, no exceptions.
- Use `snake_case` for variables and functions, `PascalCase` for classes.
- Every module must have a one-line docstring at the top explaining what it does.
- Keep functions short. If a function is longer than 30 lines, question why.

## This Project Specifically
- We are building fast (deadline: today). Keep explanations tight but don't skip the 'why'.
- We still go one file at a time and wait for approval before moving on.
- No over-engineering. SQLite is fine. A JSON file as the feed is fine.
- Commits are in past tense without prefixes: e.g., `added validator module`.
